# RootRise

Нативная idle-игра для iOS про развитие дерева и его корневой системы.

## Что внутри

- живая Canvas-анимация кроны, ствола и разрастающихся корней;
- автоматическое накопление солнечного света и рост в фоне;
- офлайн-доход после возвращения в игру;
- три улучшения: солнечный обмен, мицелий и боковые корни;
- сохранение состояния через `UserDefaults`;
- экраны «Роща», «Улучшения» и «Дневник роста»;
- чистый SwiftUI без сторонних зависимостей.

## Сборка IPA на macOS

1. Откройте `RootRise/RootRise.xcodeproj` в Xcode.
2. В Signing & Capabilities выберите свою Team и при необходимости измените Bundle Identifier.
3. Выберите `Any iOS Device (arm64)` или подключённый iPhone.
4. Выполните `Product → Archive`.
5. В Organizer выберите архив и нажмите `Distribute App`.

Текущая среда Windows не содержит Xcode и iOS SDK, поэтому IPA-файл нельзя физически собрать здесь. Сам проект уже подготовлен для сборки на macOS.
